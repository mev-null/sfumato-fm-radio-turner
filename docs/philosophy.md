# 思想・哲学

本プロジェクトの設計を貫く思想を定義する。設計判断の源泉はこのファイルにあり、思想の記述はここに集約する。他のドキュメントは思想を再記述せず、本ファイルを参照する。現在地は [architecture.md](architecture.md)、決定は [adr/](adr/)、進捗は [roadmap.md](roadmap.md) が扱う。

## sfumato — 境界を溶かす

sfumato は輪郭をぼかす絵画技法を指す。本プロジェクトは境界を溶かすことを設計の核に据える。対象とする境界は二つである。

- 放送音声と聴取環境の境界。受信した放送と、その場の音響環境を分離せず連続させる。
- 音と音の境界。状態やエフェクトの遷移を離散でなく連続とし、切替点を残さない(Morphing)。

溶かすのは信号と体験の境界であり、コードベース(algo / hdl)の境界ではない。開発上の責務分離はむしろ保つ。

## メルロ=ポンティの身体性

知覚は身体を介して世界と結びつく。主体と世界の境界は身体において溶ける。本受信機を、信号を機械的に処理する装置ではなく、環境を知覚し自らの音を適応させる身体として定義する。マイクによる知覚、場の理解、音の変容が一つの身体的ループを成す。
