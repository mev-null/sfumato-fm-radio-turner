# ADR-007: [algo] ステレオ・セパレーションの確立 — 遅延整合 + 搬送波位相補正 + PLL 帯域

- ステータス: Accepted
- 日付: 2026-06-07
- 領域: algo
- 関連: [../roadmap.md](../roadmap.md)(1.5.3 / 1.7)/ [adr-006-receiver-filter-fir-iir.md](adr-006-receiver-filter-fir-iir.md) / [adr-005-demod-quality-gate.md](adr-005-demod-quality-gate.md)

## コンテキスト

ステレオ・セパレーション(L 駆動・R 無音での 駆動側÷漏れ側 電力比)が **0.84dB**(目標 Sony 42dB)で、ほぼ分離できていなかった。測定で原因を切り分けると、すべて**群遅延=位相のズレ**だった:

1. **38kHz 搬送波の位相ズレ(最大要因)**。sub 経路の BPF が副搬送波を遅らせる一方、PLL 搬送波は生 MPX のパイロットから作るため、検波 `carrier × subm` の位相が合わず潰れる。
2. **main/sub の経路群遅延差**。main は LPF 1 段、sub は BPF→検波→LPF と段数が違い、L=main±sub の打ち消しが不完全。
3. これらは IIR の非線形位相が「副搬送波 = 2×パイロット」関係を壊すことに起因(→ 線形位相 FIR 化は ADR-006)。

実測で到達上限も確認した(線形位相 FIR + 位相/振幅/遅延 整合で 52dB、PLL 搬送波 + 最適位相で 45dB)→ **42dB は到達可能**。線形位相 FIR(ADR-006)を前提に、整合の具体方式を決める。

## 決定

ステレオ復調(`receiver._stereo_decode`)を次の整合で確立する:

- **群遅延整合**: main LPF・sub BPF を同長の線形位相 FIR にし(ADR-006)、sub は BPF(D)+LPF(D)=2D、main は LPF(D)。**main を D 遅らせて両者を 2D に揃える**(遅延ライン)。これで L=main+sub / R=main−sub の打ち消しが成立。
- **搬送波の位相補正**: 38kHz 再生搬送波を副搬送波に位相整合する。PLL の**ループは変えず、NCO 出力に定数位相オフセット**を足す(`pll.PilotPLL(out_phase_offset=...)`)。値は `settings.STEREO_CARRIER_PHASE_RAD = 4.1888`(240°)。**フィルタ群遅延で決まる決定論値**で PLL 帯域には依存しない(±10° で約 6dB 低下するため、フィルタ構成を変えたら取り直す)。検波の振幅補償 ×2.0 は整合後の最適値 ≈2.0 で維持。
- **PLL 帯域の最適化**: `PLL_BANDWIDTH` を 50→**200Hz**。高 SNR では律速が NCO の追従残差 ε(38kHz で 2ε に拡大)で、**広帯域ほどロックが締まり ε が減って分離が上がる**(実測: 50Hz→38dB / 120Hz→42dB / 200Hz→45dB)。低 SNR では分離の律速が加算ノイズ底に移り、広帯域による位相ノイズ増は埋もれて**悪化しない**ことを SNR スイープ(40〜5dB)で確認。
- 結果: セパレーション **0.84→45.04dB**(Sony 42dB 超過 → ハードゲート昇格)。

**スコープ外(今回やらない)**: 上流チャネル選択の FIR 化で 52dB まで詰める案(42dB 達成済みで不要)。複数 SNR スイープのゲート化、適応 PLL 帯域。

## 影響

### 良い影響
- セパレーションが Sony 42dB に到達し、MVP のステレオ受信が方式として成立。roadmap 1.7 の合格(Sony 絶対ゲート全昇格)に対し残るは SINAD のみ。
- 将来の移植メモ: 遅延整合は遅延ライン(シフトレジスタ)、搬送波位相補正は位相加算レジスタに対応し、ハードウェアへも素直に移せる構造になっている。
- THD/SINAD はモノラル経路(搬送波非依存)で測るため、本変更で悪化しない(ADR-005 追記参照)。

### 受け入れるトレードオフ / 負の影響
- 搬送波位相補正は**フィルタ構成依存の定数**(FIR 長などを変えたら取り直し)。±10° で約 6dB 落ちる感度。
- PLL 広帯域は本来「低 SNR でのノイズ耐性」とトレードオフ。今回の評価範囲(40〜5dB)では悪化しないと実測したが、単一トーン・定常条件での確認に留まる。

### 将来への含み
- 動的条件(音楽・フェージング)や更に低い SNR での PLL 帯域は要再検討。適応帯域(取得時は広く・追従時は狭く=gear-shift)も選択肢。
- 位相補正定数は、上流を線形位相化すれば「群遅延ぶんの遅延」で原理的に決まる形にできる(本筋化の余地、52dB)。
